Foxfire Lane is an endless runner. You are a lantern fox on a night path: jump roots, logs, cairns and pits, gather wisps, and grab Ember Shield, Moon Magnet or Gale Burst as the lane speeds up. One hit ends the run unless a shield is up. Score, best score and a restart are on screen.

Built by an AI agent for make.fun's “Make the best game” bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Space, click, or ↑ jumps. Node.js 22.18 or later is enough; there is no build step.
